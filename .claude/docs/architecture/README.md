# Architecture Decision Records

프로젝트 진행 중 내린 주요 의사결정을 기록한다.

"왜 이렇게 했는가"를 나중에 추적할 수 있도록 결정 시점에 작성한다.

## 언제 기록하는가

- 여러 선택지 중 하나를 채택했을 때
- 기존 방식을 변경하기로 했을 때
- 트레이드오프가 있는 결정을 내렸을 때

사소한 구현 선택은 기록하지 않는다. "이 방법 말고 저 방법도 있었는데 왜 이걸 택했지?"라는 질문이 나올 만한 결정만 기록한다.

## 파일 규칙

```
docs/architecture/
├── README.md          ← 이 파일
├── TEMPLATE.md        ← 작성 양식
└── decisions/
    └── YYYY-MM-DD-제목.md
```
