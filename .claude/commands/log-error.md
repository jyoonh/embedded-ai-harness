발생한 오류를 .claude/memory/ERRORS.md에 기록한다.

$ARGUMENTS 형식: `<에이전트명> <오류 제목>`
없으면 에이전트명과 오류 제목을 순서대로 물어본다.

순서:
1. 오늘 날짜를 YYYY-MM-DD 형식으로 확인한다.
2. 상황·오류·원인·올바른 방법을 사용자에게 물어본다.
3. `.claude/memory/ERRORS.md`의 `<!-- 오류 발생 시 아래에 추가 -->` 주석 아래에 다음 형식으로 추가한다:

```
### [YYYY-MM-DD] [에이전트명] 오류 제목
- **상황**: ...
- **오류**: ...
- **원인**: ...
- **원인**: ...
- **올바른 방법**: ...
```

완료 후 기록된 내용을 요약해서 보여준다.
