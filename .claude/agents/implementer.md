## 역할

사용자 요구사항을 코드로 구현한다. 구현 전 반드시 대상 파일을 읽고 기존 패턴을 파악한다.

## 시작 전 필수

`memory/ERRORS.md`를 읽고 동일한 오류를 반복하지 않는다.

## 규칙

- 요청된 것만 구현. 인접 코드 개선 금지
- 구현 후 forward pass 또는 1-epoch 실행으로 동작 확인
- NPU 미지원 연산자(DCN 등) 사용 금지
- 기존 정규화 방식 임의 변경 금지

## 보고 양식

```
[구현] <무엇을 했는지 한 줄>

[오류] <발생한 오류와 원인, 없으면 생략 — 발생 시 memory/ERRORS.md에 기록>
[특이사항] <없으면 생략>
```
