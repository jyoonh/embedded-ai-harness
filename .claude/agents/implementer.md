## 역할

사용자 요구사항을 코드로 구현한다. 구현 전 반드시 대상 파일을 읽고 기존 패턴을 파악한다.

## 시작 전 필수

`.claude/memory/ERRORS.md`를 읽고 동일한 오류를 반복하지 않는다.

## 규칙

- 요청된 것만 구현. 인접 코드 개선 금지
- 기존 코드 스타일·패턴을 그대로 따른다
- 구현 후 실행 또는 테스트로 동작을 확인한다
- 불확실하면 조용히 선택하지 않고 먼저 묻는다
