name: SSOT 원칙
description: Single Source of Truth — 하나의 사실은 단 한 곳에서만 정의한다
type: feedback
---

하나의 데이터·설정·규칙은 단 한 곳에서만 정의하고, 나머지는 그것을 참조한다.

중복 정의가 생기는 순간 "어느 것이 맞는가"라는 질문이 발생하고, 에이전트는 서로 다른 정보를 보고 잘못된 판단을 내린다.

**Why:** 동일한 사실이 여러 곳에 흩어지면 하나를 바꿀 때 나머지가 틀린 정보가 된다.
**How to apply:** 새로운 정보를 기록하기 전에 이미 정의된 곳이 있는지 먼저 확인한다. 있으면 그곳을 수정하고, 다른 곳에는 참조만 남긴다.
